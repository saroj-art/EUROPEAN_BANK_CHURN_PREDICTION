# EUROPEAN_BANK_CHURN_PREDICTION
An end-to-end machine learning and Streamlit analytics application for predicting customer churn risk.

## Project Objective

The goal is to predict customer churn probability, identify major churn drivers, and provide actionable customer-retention insights.

## Machine Learning Workflow

- Data preprocessing
- Categorical encoding
- Feature engineering
- Train-test split
- Standard scaling
- Class imbalance handling using SMOTE
- Model comparison
- Gradient Boosting model selection
- Probability-based churn prediction
- Threshold-based classification
- Feature importance analysis
- What-if scenario analysis
- Streamlit deployment

## Final Model

Gradient Boosting Classifier

## Dashboard Features

- Executive Dashboard
- Customer Churn Risk Calculator
- Portfolio Insights
- Feature Importance
- What-If Simulator
- Model Performance
- Business Recommendations

## Key Business Drivers

The analysis highlights factors such as:

- Age
- Number of products
- Customer activity
- Balance
- Geography
